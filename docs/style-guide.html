1. 總覽

VTaxon 前端沒有 CSS 檔案、沒有 Tailwind、沒有 CSS-in-JS 函式庫。所有樣式都是 TSX 元件裡的 inline style 物件；唯一的全域樣式表內嵌在 frontend/index.html（base、keyframes、3 個 utility class）。

整體視覺語言：深色單一主題（無淺色模式）、玻璃擬態點綴（backdrop blur）、 「tinted 按鈕」公式（半透明底 + 同色邊 + 同色字）、以半透明白階層區分文字層級。

  • Navbar：fixed、高 44px、rgba(8,13,21,0.85) + blur(12)、底線 rgba(255,255,255,0.06)。 高度 44 被硬編碼在 5 處：App.tsx mainStyle、PreviewPanel、VtuberDetailPanel、YouTubeChannelBanner、LoginPage
